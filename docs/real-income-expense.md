# 実収入・実支出の考え方

finplan の「3. 加工」にある実収入・実支出のカードの背景となる考え方をまとめたものです。画面の「ⓘ」には要点だけを載せ、詳しい説明はこのファイルに置いています。

## 1. 家計簿に混ざっている2種類の出入り

家計簿は、管理しているお金（財布や、家計簿で記録している口座）の出入りを1行ずつ記録する**単式簿記**です。その出入りには、性質の違う2種類が混ざっています。

| 種類 | 例 |
|---|---|
| 稼いだお金・使ったお金 | 給与、事業の売上、食費、家賃 |
| 管理しているお金と、その外（貯蓄用の口座、証券口座など）との間の移動 | 積立、証券口座への入金、貯金の引き出し、株の売却代金の受け取り |

後者は資産の置き場所が変わっただけで、豊かになったわけでも、何かにお金を使ったわけでもありません。これを除くと前者だけが残ります。これが**実収入**と**実支出**です。

複式簿記では、1つの取引を必ず2つの面（たとえば「現金が減った」と「投資が増えた」）で記録するので、移動と損益の区別が記録の仕組みに組み込まれています。単式簿記にはその仕組みが無いので、後から分ける必要があります。

## 2. 見分け方（2つの問い）

1. **管理しているお金の線をまたぐか？**
   またがなければ、そのまま収入・支出です（口座の中で付く利息、ふだんの買い物など）。
2. **またぐなら、自分のお金の置き場所が変わっただけか、新しく生まれた・受け取ったお金か？**
   置き場所が変わっただけなら除き、新しく生まれた・受け取ったお金なら実収入（または実支出）です。

線をまたぐことは移動の必要条件ですが、それだけでは決まりません。給与も外から入ってきますが、新しく受け取ったお金なので実収入です。

| 記録の例 | 線をまたぐか | 置き場所の移動か | 扱い |
|---|---|---|---|
| 給与 | またぐ | 新しく受け取ったお金 | 実収入 |
| 管理している口座の利息 | またがない | — | 実収入 |
| 国債の利息、株の配当（管理している口座に入る） | またぐ | 元本から新しく生まれたお金 | 実収入 |
| 国債の満期で戻る元本 | またぐ | 移動 | 実収入から除く |
| 株の売却代金 | またぐ | 移動（売却益も含めてまとめて扱う。4. を参照） | 実収入から除く |
| 証券口座への入金、積立 | またぐ | 移動 | 実支出から除く |
| 贈与などの臨時収入 | またぐ | 新しく受け取ったお金 | 目的しだい（下記） |

積立と引き出しは向きが逆の移動なので、どちらか片方だけ除いても、もう片方は打ち消されません。両方とも除く必要があります。

臨時収入は、定義のうえでは実収入です（家計調査では「特別収入」）。ただ、毎月の生活費を稼ぎでまかなえるかを見たい場合は、除いたほうが判断しやすくなります。

## 3. 総務省「家計調査」との対応

実収入・実支出は、総務省統計局の家計調査で使われている言葉です。家計調査では、世帯の受取と支払を次のように分けています。

- 受取 ＝ 実収入 ＋ 実収入以外の受取 ＋ 繰入金（前月から持ち越した手持ちの現金）
- 支払 ＝ 実支出 ＋ 実支出以外の支払 ＋ 繰越金（翌月へ持ち越す現金）
- 受取と支払は必ず一致する

| 家計調査の言葉 | 意味 |
|---|---|
| 実収入 | 世帯員全員の現金収入の合計（税込み）。利子・配当は「財産収入」としてここに入る |
| 実収入以外の受取 | 現金は入るが、資産の減少や負債の増加を伴う「見せかけの収入」。預貯金の引き出し、有価証券の売却、借入金など |
| 実支出 | 消費支出 ＋ 非消費支出（税・社会保険料） |
| 実支出以外の支払 | 現金は出るが、資産の増加や負債の減少を伴う「見せかけの支出」。預貯金、投資、借金の返済など |
| 黒字 | 実収入 − 実支出（マイナスなら赤字）。可処分所得 − 消費支出 と同じ値 |

家計調査の実収入は税込みです。給与を手取りで記録している場合、finplan の実収入は可処分所得（税・社会保険料を引いた額）に近い数字になります。ただし、黒字は「可処分所得 − 消費支出」と同じ値なので、黒字そのものは変わりません。

## 4. 投資の扱い

株などの売却代金には、元本（置き場所の移動）と売却益（新しく生まれたお金）が混ざっています。本来は分けるのが筋ですが、元本を出すには、買ったときの金額（取得原価）を銘柄ごとに追い続ける必要があります。家計調査でも、有価証券の売却は売った金額をまとめて「実収入以外の受取」として扱っています。finplan でも、まとめて除くのが手軽です。

その場合、**売却による損得は実収入・実支出のどちらにも出てきません**。儲けが出ていれば資産は黒字より多く増えており、損が出ていれば黒字ほどは増えていません。まだ売っていない投資の値動きも、もともと家計簿の外の話なので出てきません。

投資の損得を知りたい場合は、家計簿ではなく、証券口座の残高（評価額）をときどき記録し、「入金した合計 − 引き出した合計」と比べるのが簡単です。

利息や配当は、最初から新しく生まれたお金だけなので、分ける手間はありません。実収入に入れます。

## 5. 加工の組み合わせごとの累積収支の読み方

「2. 支出と収入」で収支を選ぶと、累積収支（期間の始めからの収支の合計）が見られます。3. のカードの組み合わせによって、意味が変わります。

| 組み合わせ | 累積収支の意味 |
|---|---|
| 加工なし | 管理しているお金の増減（期間末の残高 − 期間の始めの残高）。家計調査の「繰越金 − 繰入金」にあたる |
| 実収入と実支出の両方 | 稼いだお金 − 使ったお金（家計調査の黒字）。臨時収入や貯金の取り崩しに頼らない、ふだんの収支 |
| 実支出だけ | 管理しているお金の増減 ＋ 積み立てた額。資産全体の増減に近い（取り崩しや投資の損得は含まない） |
| 実収入だけ | 稼いだお金 −（使ったお金 ＋ 積み立てた額）。積立まで含めて、稼ぎだけでまかなえたか |

4つは次の式でつながっています。

```
加工なしの累積
  = 実収入 − 実支出（両方の累積）
  + 実収入から除いた収入
  − 実支出から除いた支出
```

家賃や必要な収入を考えるときに一番大事なのは「両方」（ふだんの収支）です。

## 6. 数字がずれる元

実収入 − 実支出 を読むときは、次のずれを念頭に置きます。

**資産全体の増減とずれるもの**
- 売却した投資の損得（4. を参照）
- まだ売っていない投資の値動き

**ふだんの収支としてずれるもの**
- 割り勘の回収やポイントでの支払いを、相殺せずに「収入から除く」だけにしている分（7. を参照）
- 記録のタイミング。クレジットカードの利用日と引き落とし日、交通系ICへのチャージと実際の利用など、どの時点で記録するかで月ごとの金額がずれます。長い期間の合計ではほぼ打ち消し合います
- 一度に大きく払うもの（家電、講座代など）。払った月にまとめて出るので、月ごとの平均を見るときは按分したほうが実態に近くなります

## 7. 相殺

割り勘の回収、会社の経費の立替の戻り、ポイントでの支払いなどは、収入でも口座間の移動でもなく、**支出を打ち消すお金（支払いの値引き）**です。

- 収入から除くだけにすると、立て替えた支出が残ったままになり、実支出が多めに出ます
- 本来は、回収した額を支出から差し引くのが正確です

収支（実収入 − 実支出）だけなら、「収入に残す」と「支出から差し引く」は同じ結果になります。違うのは実収入と実支出それぞれの金額です。生活費（実支出）を正しく知りたい場合は、支出から差し引く形にします。

finplan の「相殺」のカードでは、収入側のカテゴリーごとに、どの支出カテゴリーから差し引くかを選びます（割り勘の回収は外食から、ポイントは食費から、など）。相殺した記録は、そのカテゴリーの支出のマイナスとして数えます。同じカテゴリーを実収入のカードで除いていても、相殺が優先されます。

投資の元本の戻りは支出の打ち消しではないので、ここには入れません（2. の「移動」です）。
