# 実収入・実支出の考え方

finplan の「3. 加工」の背景となる、実収入・実支出の考え方をまとめたものです。画面の「ⓘ」には要点だけを載せ、詳しい説明はこのファイルに置いています。相殺の向きや生活費の定義は [offset-and-living-cost.md](offset-and-living-cost.md) にあります。

## 1. 家計簿に混ざっている記録の種類

家計簿は、管理しているお金（財布や、家計簿で記録している口座）の出入りを1行ずつ記録する**単式簿記**です。その出入りには、性質の違う記録が混ざっています。

| 種類 | 例 | 扱い |
|---|---|---|
| 稼いだお金・使ったお金 | 給与、事業の売上、利息、食費、家賃 | 残す（これが**実収入**・**実支出**） |
| 管理しているお金と、その外（貯蓄用の口座、証券口座など）との移動 | 積立、証券口座への入金、貯金の引き出し、株の売却代金 | 除外（2.） |
| 前の支出を打ち消すお金 | 割り勘の回収、返金、ポイントでの支払い | 相殺（7.） |

移動は資産の置き場所が変わっただけで、豊かになったわけでも、何かにお金を使ったわけでもありません。打ち消すお金は、受け取ったように見えて、実際には前の支払いが少なかったということです。

複式簿記では、1つの取引を必ず2つの面（たとえば「現金が減った」と「投資が増えた」）で記録するので、この区別が記録の仕組みに組み込まれています。単式簿記にはその仕組みが無いので、後から分ける必要があります。

## 2. 実収入・実支出の見分け方

実収入・実支出かどうかは、**お金として持っている財産（現金・預金・証券など − 借金）が増減したか**で見分けます。増減しなければ移動です。家電などの物を買うのは、物は残っても、家計調査でも消費支出として扱うとおり支出です。

管理しているお金の外とのやり取りかどうかでは決まりません。給与も買い物も外とのやり取りですが、給与は財産を増やし、買い物は減らすので、実収入・実支出です。

| 記録の例 | 正味の財産 | 扱い |
|---|---|---|
| 給与、贈与などの臨時収入 | 増える | 実収入 |
| 食費、家賃、家電の購入 | 減る | 実支出 |
| 利息、配当 | 増える（元本から新しく生まれたお金） | 実収入 |
| 証券口座への入金、積立 | 変わらない（置き場所が変わる） | 実支出から除く |
| 貯金の引き出し、国債の満期で戻る元本 | 変わらない（置き場所が変わる） | 実収入から除く |
| 株の売却代金 | 変わらない（株が現金に変わる。売却益は 4.） | 実収入から除く |
| 借入、借金の返済 | 変わらない（借金が増える・減る） | 実収入・実支出から除く |

積立も引き出しも移動なので、両方とも除きます（片方だけ除いたときの収支の意味は 5.）。

割り勘の回収も、立て替えた分が戻っただけなので財産は増えません。ただし、打ち消す相手（立て替えた支出）が家計簿の中にあるので、除外ではなく相殺します（7.）。

臨時収入は、定義のうえでは実収入です（家計調査では「特別収入」）。除くと、収支は「臨時収入が無かったら」の数字になります（[offset-and-living-cost.md](offset-and-living-cost.md) の 2.）。

## 3. 総務省「家計調査」との対応

実収入・実支出は、総務省統計局の家計調査で使われている言葉です。家計調査では、世帯の受取と支払を次のように分けています。

- 受取 ＝ 実収入 ＋ 実収入以外の受取 ＋ 繰入金（前月から持ち越した手持ちの現金）
- 支払 ＝ 実支出 ＋ 実支出以外の支払 ＋ 繰越金（翌月へ持ち越す現金）
- 受取と支払は必ず一致する

| 家計調査の言葉 | 意味 |
|---|---|
| 実収入 | 世帯員全員の現金収入の合計（税込み）。利子・配当は「財産収入」としてここに入る |
| 実収入以外の受取 | 現金は入るが、資産の減少や負債の増加を伴う「見せかけの収入」。預貯金の引き出し、有価証券の売却、借入金など |
| 実支出 | 消費支出 ＋ 非消費支出（税・社会保険料） |
| 実支出以外の支払 | 現金は出るが、資産の増加や負債の減少を伴う「見せかけの支出」。預貯金、投資、借金の返済など |
| 黒字 | 実収入 − 実支出（マイナスなら赤字）。可処分所得 − 消費支出 と同じ値 |

家計調査の実収入は税込みです。給与を手取りで記録している場合、finplan の実収入は可処分所得（税・社会保険料を引いた額）に近い数字になります。黒字は「可処分所得 − 消費支出」と同じ値なので、記録の仕方によらず変わりません。

手取りと比べるときは、税・社会保険料を手取りと生活費のどちらか一方で数えます（[offset-and-living-cost.md](offset-and-living-cost.md) の 1.）。

## 4. 投資の扱い

株などの売却代金には、元本（置き場所の移動）と売却益（新しく生まれたお金）が混ざっています。本来は分けるのが筋ですが、元本を出すには、買ったときの金額（取得原価）を銘柄ごとに追い続ける必要があります。家計調査でも、有価証券の売却は売った金額をまとめて「実収入以外の受取」として扱っています。finplan でも、まとめて除くのが手軽です。

その場合、**売却による損得は実収入・実支出のどちらにも出てきません**。儲けが出ていれば資産は黒字より多く増えており、損が出ていれば黒字ほどは増えていません。まだ売っていない投資の値動きも、もともと家計簿の外の話なので出てきません。

投資の損得を知りたい場合は、家計簿ではなく、証券口座の残高（評価額）をときどき記録し、「入金した合計 − 引き出した合計」と比べるのが簡単です。

利息や配当は、最初から新しく生まれたお金だけなので、分ける手間はありません。実収入に入れます。

## 5. 除外の組み合わせごとの累積収支の読み方

「2. 支出と収入」で収支を選ぶと、累積収支（期間の始めからの収支の合計）が見られます。何を除外したかで意味が変わります。相殺は収支を変えないので、相殺の有無にはよりません（差し引く先が除外に当たって一緒に除いた相殺は、除外に数えます）。

| 除外したもの | 累積収支の意味 |
|---|---|
| なし | 管理しているお金の増減（期間末の残高 − 期間の始めの残高）。家計調査の「繰越金 − 繰入金」にあたる |
| 移動を両側とも | 実収入 − 実支出（家計調査の黒字）。外の口座まで含めた資産全体の増減から、運用の損益を除いたもの |
| 支出側の移動だけ（積立など） | 黒字 ＋ 引き出した額。引き出しを収入のまま数える |
| 収入側の移動だけ（引き出しなど） | 黒字 − 積み立てた額。積立まで含めて、稼ぎだけでまかなえたか |

どの組み合わせも、次の式でつながっています。

```
加工なしの累積 = 加工後の累積 ＋ 除外した収入 − 除外した支出
```

暮らし向きを収支で見るなら、移動を両側とも除いた形（黒字）が基本です。

## 6. 数字がずれる元

**資産全体の増減とずれるもの**
- 売却した投資の損得と、まだ売っていない投資の値動き（4.）

**生活費としてずれるもの**
- 家計簿の外で払っているもの。給与からの天引きや、記録していない口座・カードからの引き落としは、支出に出てきません
- 打ち消すお金（割り勘の回収など）を、相殺せずに除外だけにしている分（7.）
- 記録のタイミング。クレジットカードの利用日と引き落とし日、交通系ICへのチャージと実際の利用など、どの時点で記録するかで月ごとの金額がずれます。長い期間の合計ではほぼ打ち消し合います
- 一度に大きく払うもの（家電、講座代など）。払った月にまとめて出るので、月ごとの平均を押し上げます。中央値と見比べるか、按分します

## 7. 支出を打ち消すお金の相殺

割り勘の回収、会社の経費の立替の戻り、返金、ポイントでの支払いなどは、収入でも移動でもなく、**前の支出を打ち消すお金（支払いの値引き）**です。たとえば4,000円を立て替えて1,500円を回収したなら、自分の支出は2,500円で、1,500円は立て替えた分が戻ってきただけです。

回収した額を R として、扱い方を比べると次のようになります。

| 扱い方 | 収入 | 支出 | 収支 |
|---|---|---|---|
| 加工なし（回収を収入に残す） | R を含む | 立て替えた分を含む | 正しい |
| 回収を除外する | R だけ減る | 立て替えた分が残る | **R だけ少なく出る** |
| 相殺（回収を支出から差し引く） | R だけ減る | R だけ減る | 正しい |

除外するだけだと、「お金が入ってきた」ことだけが消えて、「立て替えて払った」ことは残るので、支出が多く、収支が少なく出ます。生活費を正しく知るには相殺します。

finplan では、収入側の条件を足し、差し引く支出のカテゴリーを選びます（割り勘の回収は外食から、ポイントは食費から、など）。内訳を気にしないなら、「その他」のようなカテゴリーにまとめても構いません。

差し引いた結果、ある月のあるカテゴリーがマイナスになることもあります（立て替えた支出と回収が別の月になった場合など）。棒グラフではマイナスの部分を0の線より下に、円グラフでは差し引いた分を内側の輪に描きます。合計はどちらでも正しく計算されます。

### 収入側の記録は3つの扱いのどれか

| 扱い | 意味 | 例 |
|---|---|---|
| 残す | 稼いだ・受け取ったお金 | 給与、利息、配当、臨時収入 |
| 除外 | 管理の外から戻ってきた自分のお金 | 貯金や証券口座からの引き出し、株の売却代金 |
| 相殺 | 支出の打ち消し | 割り勘の回収、経費の精算、返金、ポイントでの支払い |

投資の元本の戻りは支出の打ち消しではないので、相殺ではなく除外です（2. の移動）。

## 8. 迷いやすい記録

### 税金・社会保険料の還付や返金

元の支払いが家計簿に出ているかで決まります。

- **出ていないもの**（給与から源泉徴収された所得税の、確定申告での還付など）：払いすぎた分が後から戻った、手取りの一部です。収入に残します。
- **出ているもの**（自分で払った住民税や国民年金の保険料の還付・返金など）：その支出を打ち消すお金なので、その支出と相殺します。
- **公的な給付金**：元の支払いは無く、定義のうえでは実収入です（家計調査では社会保障給付や特別収入）。臨時収入と同じく、残すのが基本です。

### 交通系ICカード・電子マネー

チャージ式のカードは、次のどれかの付け方に決めておくと迷いません。

| 付け方 | チャージ | 使ったとき |
|---|---|---|
| A: チャージした時点で使ったとみなす | 支出として記録する | 記録しない |
| B: 残高を財布と同じ「管理の内側」とする | 記録しない（管理の内側での移動） | 支出として記録する |
| C: 残高を「管理の外」とする | 管理の外への移動として記録する（除外） | 支出として記録し、同じ額を管理の外からの移動として記録する（除外） |

A は一番簡単です。B と C は、使った日と金額が正確に残ります。A のまま使ったときも記録すると、チャージと二重に数えてしまうので、同じ額を打ち消す記録が必要になります。その打ち消しは交通費の取り消しなので、相殺します。

### 付け方を途中で変えたとき

たとえば A（チャージで支出）から B（残高は管理の内側）に変えたときは、切り替えた時点の残高に注意します。その残高は、A のときにチャージで支出として数えたのに、まだ使っていないお金です。B に変えると、これから使ったときにもう一度支出として数えるので、**切り替えた時点の残高を1回だけ、その支出から差し引きます**（相殺）。管理の外からの移動として除外すると、数えすぎた支出が残ります。

ほかの付け方の変更でも同じで、「変える前の付け方で、すでに数えたもの・まだ数えていないもの」が、変えた後の付け方で二重にならないか、抜けないかを確かめます。
