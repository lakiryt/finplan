# 相殺と、目的に合わせた生活費の定義

finplan の「3. 加工」で相殺と除外をどう使い分けるか、また生活費をどう定義するかについての整理です。実収入・実支出そのものの説明は [real-income-expense.md](real-income-expense.md) にあります。

## 1. 生活費の範囲は目的で決める

家賃も、一度だけの大きな支出（家電、講座代など）も、使ったお金であることに変わりはありません。どこまでを「生活費」として見るかは、何を知りたいかで決めます。

| 知りたいこと | 生活費として見る範囲の例 |
|---|---|
| 引っ越し先の家賃をいくらまでにできるか | 家賃以外の支出 |
| ふだんの暮らしにいくらかかるか | 一度だけの大きな支出を按分した（または除いた）支出 |
| 稼ぎで暮らしをまかなえているか | 実支出（移動だけを除いた支出）全体 |

過去の生活費から、これからの予算（家賃・必要な手取りなど）を見積もるときは、次の点に気を付けます。

- **一度だけの支出も、形を変えてまた起きます。** 一度だけの支出をすべて除くと、生活費を少なく見積もります。除くより、按分するか、平均（一度だけの支出に引っ張られる）と中央値（引っ張られにくい）を見比べます。
- **税・社会保険料は、手取りと生活費のどちらか一方で数えます。** 天引きされるものは手取りから引かれているので、生活費には入れません。自分で払うものは、生活費に入れるか、支出 → 収入で相殺して収入から引きます（4.）。働き方が変わると、天引きされるものと自分で払うものの分かれ方も変わります。

## 2. 片側だけ除くと、収支は「それが無かったら」の数字になる

家賃を支出から除くだけだと、支出は見たい金額になりますが、収支（収入 − 支出）は家賃の分だけ良くなります。実際にはその分のお金は残っていないので、収支は「家賃が無かったら」という、実際の増減とは違う数字になります。収入側も同じで、臨時収入を除くだけだと、収支は「臨時収入が無かったら」の、実際より悪い数字になります。

支出の範囲を変えても収支を実際のままにするには、**同じ額を収入からも差し引きます**。そうすると、その支出は「最初から無かった」のと同じ扱いになり、収支は変わりません。これが支出 → 収入の相殺です。

臨時収入には差し引く相手が無いので、残すのが基本です。除くなら、「ふだんの稼ぎだけだったら」を見る厳しめの数字として読みます。

## 3. 相殺の向きは、額を決める記録がどちら側にあるかの違い

相殺は、同じ額を収入と支出の両方から差し引く操作で、収支は変わりません。向きの違いは、額を決める記録がどちら側にあるかと、差し引いた分が反対側のどの内訳に付くかだけです。

| | 額を決める記録 | 差し引く反対側の内訳 |
|---|---|---|
| 収入 → 支出 | 収入側（割り勘の回収、返金、ポイントなど） | 立て替えた支出などのカテゴリーか、指定なし |
| 支出 → 収入 | 支出側（家賃、自分で払う税・社会保険料など） | 給与などのカテゴリーか、指定なし |

差し引く先は内訳の見え方だけの違いなので、全体の金額が正しければよいなら指定しなくても構いません。

## 4. 支出 → 収入の相殺をしたとき、収入は何を表すか

収入から家賃を差し引いた額は、「**家賃を払った後に、自由に使えるお金**」です。ほかの支出でも同じで、差し引いたものを払った後に使えるお金になります。

これは、総務省の家計調査の「可処分所得」（実収入から、税金・社会保険料などの「非消費支出」を引いた額）と同じ構造です。家計調査では税金・社会保険料を「収入の目減り」として収入側から引きますが、ここではその「引くもの」を目的に合わせて選んでいる、と考えられます。

## 5. 相殺が原則で、除外は「相手方が外にある相殺」

収支を実際の数字に保つには、打ち消し合うものを両方とも消すのが原則です。除外に見える操作も、相手方が家計簿の外にある相殺だと考えられます。

| 種類 | 打ち消す相手 | 例 | 扱い | 収支 |
|---|---|---|---|---|
| 支出の打ち消し | 家計簿の中の支出 | 割り勘の回収と立て替えた支出、返金と元の支払い | 相殺（収入 → 支出） | 変わらない |
| 収入の目減り | 家計簿の中の収入 | 自分で払う税金・社会保険料、個人事業の経費 | 相殺（支出 → 収入） | 変わらない |
| 見る範囲から外すもの | 家計簿の中の収入（目的に合わせて引く） | 家賃 | 相殺（支出 → 収入） | 変わらない |
| 移動 | 家計簿の外の口座の残高 | 積立、証券口座への入金、貯金の引き出し、株の売却代金 | 除外 | 管理しているお金の増減から、資産全体の増減に変わる |

**移動は、外の口座の残高を相手方にした相殺です。** 積立で出ていった額は、外の口座の残高が同じだけ増えることで打ち消されます（引き出しはその逆）。外の口座まで含めた資産全体で見れば何も起きていませんが、家計簿には片側しか記録されないので、その片側を除外すれば打ち消したことになります。積立も引き出しも移動なので、両方を除きます。

除外した後の収支は、外の口座まで含めた資産全体の増減になります。ずれるのは、外で生まれた運用の損益（売却益や評価額の値動き）だけです（[real-income-expense.md](real-income-expense.md) の 4.）。

一方、家賃や臨時収入のような、本当に受け取った・使ったお金には、打ち消す相手がありません。片側だけ除外すると、2. のとおり「それが無かったら」の数字になります。

このため、finplan の「3. 加工」では相殺を先に置き、家計簿の中で打ち消せるものを先に打ち消してから、相手方が外にあるものだけを除外で除く順番にしています。

一度だけの大きな支出は、範囲から外す代わりに、何か月かに分けて計上する（按分する）方法もあります。使ったこと自体は残したまま、月ごとの偏りだけをならします（按分の工程はまだありません）。

## 6. 対象はカテゴリーより細かく指定する

家計簿のカテゴリーには、性質の違う記録が混ざっていることがよくあります（たとえば「日用品」に家電の買い替えが、「交通費」に旅行の移動が入っているなど）。そのため、相殺・除外の対象は、カテゴリー単位ではなく条件で指定します。

- 収入側か支出側か
- カテゴリー
- メモ（文字や正規表現）
- 期間
- 一覧から選んだ記録

メモの付け方は揃っていないことが多く（同じ種類の支払いでも書き方が違う、空欄があるなど）、メモや期間だけでは絞りきれないことがあります。そのときは、記録の画面の一覧で記録を1件ずつ選びます。入力欄は記録を探すための検索として使い、検索を変えても選んだ記録は残るので、「メモで探して選ぶ → 期間で探して、メモが空欄のものも選ぶ」のように集められます。記録を選んで条件にすると、条件は選んだ記録だけになります。

選んだ記録は、CSVの何行目かではなく、記録の中身（日付・金額・カテゴリー・メモ）で見分けます。そのため、CSVを書き出し直しても同じ記録を指せます。中身がすべて同じ記録は区別しません（扱いを分ける理由がないため）。家計簿アプリで記録を書き換えると見分けられなくなるので、記録の画面に「見つからない記録」として件数を出します。

## 7. 画面での扱い

相殺と除外は、同じ1種類の条件です。条件に当たる記録をその側から除き、反対側の差し引く先を選べば、そこからも同じ額を差し引きます（相殺）。「差し引かない」を選べば、除くだけです（除外。移動に使う）。差し引く先は、反対側のカテゴリーか、指定なし（どのカテゴリーにも付けずに反対側の全体から差し引く。グラフでは「差し引き（指定なし）」として灰色で出す）です。

条件は、記録の画面で作ります。記録の画面は、検索した記録を一覧にするもので、2. の棒グラフ（押した月で絞った検索）や、3. の「＋ 条件を追加」・条件のバッジから開きます。一覧には、それぞれの記録に今の加工で何が起きているかも出します。

「3. 加工」では、条件を「支出側からの相殺」「支出側からの除外」「収入側からの相殺」「収入側からの除外」の4つに分けて、バッジとして並べます。区分ごとにまとめて有効・無効を切り替えられます。

1つの記録が相殺と除外の両方に当たるときは、相殺を優先します。差し引く先が除外の条件に当たるときは、相殺した分も一緒に除きます。これはその記録を除外するのと同じなので、カテゴリー全体を除外しているカテゴリーは、差し引く先に選べないようにしています（相手方が家計簿の外にある相殺が除外、という 5. の考え方とも一致します）。
