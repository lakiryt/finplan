# 相殺と、目的に合わせた生活費の定義

finplan の「3. 加工」で相殺をどう考えるか、また生活費をどう定義するかについての整理です。実収入・実支出そのものの説明は [real-income-expense.md](real-income-expense.md) にあります。

## 1. 生活費の定義は目的によって変わる

家賃も、一度だけの大きな支出（講座代、家電など）も、使ったお金であることに変わりはなく、れっきとした生活費です。どこまでを「生活費」として見るかは、何を知りたいかによって変わります。

| 知りたいこと | 生活費として見る範囲の例 |
|---|---|
| 引っ越し先の家賃をいくらまでにできるか | 家賃以外の支出 |
| ふだんの暮らしにいくらかかるか | 一度だけの大きな支出を除いた支出（または按分した支出） |
| 稼ぎで暮らしをまかなえているか | 実支出（移動だけを除いた支出）全体 |

## 2. 単に除くと、収支が意味のない数字になる

家賃や講座代を支出から除くだけだと、支出は見たい金額になりますが、収支（収入 − 支出）はその分だけ良く見えます。しかし、現実には何も増えていないので、その収支には意味がありません。

収支を現実のままに保ちつつ支出の範囲を変えるには、**同じ額を収入からも差し引きます**。そうすると、その支出は「最初から無かった」のと同じ扱いになり、収支は変わりません。これは相殺と同じ操作です。

## 3. 相殺は向きではなく「どのくくりで見つけるか」の違い

相殺は、同じ額を収入と支出の両方から差し引く操作です。収支は変わりません。違いは、次の2点だけです。

| | 相殺する額を見つけるくくり | 差し引いた分を付ける反対側の内訳 |
|---|---|---|
| 収入 → 支出 | 収入側のカテゴリー（割り勘の回収、返金、ポイントなど） | 支出側のカテゴリー（立て替えた支出など）か、指定なし |
| 支出 → 収入 | 支出側のカテゴリー（家賃、講座代など） | 収入側のカテゴリー（給与など）か、指定なし |

全体として両方から同じ額を引くので、収支への影響はどちらも同じです。どちらを使うかは、家計簿の付け方によって、相殺したい額がどちら側のくくりで見つけやすいかで決まります。

- 割り勘の回収や返金を、収入側の1つのカテゴリーにまとめて記録しているなら、収入側で見つける（収入 → 支出）
- 家賃のように、取り除きたい支出が支出側のカテゴリーにまとまっているなら、支出側で見つける（支出 → 収入）

## 4. 支出 → 収入の相殺をしたとき、収入は何を表すか

収入から家賃や講座代を引いた額は、「**それらを払った後に、自由に使えるお金**」です。

これは、総務省の家計調査の「可処分所得」（実収入から、税金・社会保険料などの「非消費支出」を引いた額）と同じ構造です。家計調査では税金・社会保険料を「収入の目減り」として収入側から引きますが、ここではその「引くもの」を目的に合わせて選んでいる、と考えられます。

家賃を決めたい場合は、「家賃以外の生活費」と「家賃以外に使える収入」が並ぶので、目的に合った見え方になります。どの収入（給与など）から差し引くかは、内訳の見え方だけの違いなので、指定しなくても構いません。

## 5. 支出側で「除く」操作の整理

支出側で何かを除く操作には、性質の違う3種類があります。

| 種類 | 意味 | 例 | 収支 |
|---|---|---|---|
| 移動の除外 | 使ったのではなく、置き場所を移しただけ | 積立、証券口座への入金 | 正しい形に直る（実支出の定義どおり） |
| 収入の目減り | 支出に見えるが、実は収入の目減り | 自分で払う税金・社会保険料、個人事業の経費 | 支出 → 収入の相殺で、変わらない |
| 見る範囲から外す | 本当に使ったお金だが、今の目的では別に見たい | 家賃、一度だけの大きな支出 | 支出 → 収入の相殺にすれば、変わらない |

「見る範囲から外す」を単なる除外にすると、2. のとおり収支が意味を失います。相殺として扱うことで、収支を保ったまま、支出の範囲だけを目的に合わせられます。

一度だけの大きな支出は、範囲から外す代わりに、何か月かに分けて計上する（按分する）方法もあります。こちらは、そのお金を使ったこと自体は残したまま、月ごとの偏りだけをならします。

## 6. 対象の指定はカテゴリー単位では粗い

家計簿のカテゴリーには、性質の違う記録が混ざっていることがよくあります（たとえば「家賃」のカテゴリーに、倉庫代や宿泊費、引っ越し費用が入っているなど）。除く・相殺の対象は、最終的には次のような条件で指定できる必要があります。

- カテゴリー
- メモ（文字や正規表現）
- 期間
- 個別の記録

個別の記録を指定するには、CSVを書き出し直しても同じ記録を指せる識別子が必要です。何行目かではなく、日付・金額・メモ・カテゴリーなどを組み合わせて識別する方法が考えられます（同じ日に同じ内容の記録が複数あると見分けられない、という限界は残ります）。

## 7. 画面のカード

「相殺 ＝ 除く ＋ 反対側からも差し引く」として、両方向を対称に扱います。

- **収入から除く／支出から除く**：それぞれ、除くものを選ぶ。移動だけを除いた場合が、家計調査でいう実収入・実支出にあたる
- **相殺**：両方の「除く」カードで除いたものを並べ、それぞれについて、反対側から差し引くかどうかと、差し引く先を選ぶ

差し引く先を指定しない場合は、どのカテゴリーにも付けずに反対側の全体から差し引きます（グラフでは「差し引き（指定なし）」として灰色で出します）。

今は対象をカテゴリー単位で指定します。メモや期間などの条件での指定は、今後対応する予定です（個別の記録の指定は、識別子の決め方を詰めてから）。
