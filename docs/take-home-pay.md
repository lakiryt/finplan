# 手取りの見積もり（給与の場合）

「4. 家賃の目安」の「想定する手取り」の「計算する」で開く窓の説明です。時給と労働時間から、**所得税だけ**を計算します。住民税と社会保険料はまだ計算しません。それぞれ何が必要かは 3. にまとめています。

金額・料率は 2026年10月時点で調べたものです。毎年のように変わるので、使う前に末尾の出典で確かめてください。

## 1. 手取りの内訳

手取り ＝ 額面（給与の総額） − 税 − 社会保険料

| 引かれるもの | この窓での扱い |
|---|---|
| 所得税（＋復興特別所得税） | 計算する |
| 住民税 | 計算しない |
| 健康保険（＋介護保険・子ども・子育て支援金） | 計算しない（1年分が分かれば入力でき、所得税の計算と手取りに反映する） |
| 年金（厚生年金・国民年金） | 同上 |
| 雇用保険 | 同上 |

通勤手当は、一定額まで所得税がかかりません（電車・バスなら月15万円まで）。額面に含めないで計算してください。

## 2. 所得税の計算

給与だけの人の、1年分の所得税（年税額）を次の順で計算します。

1. **月の給与**: 時給 × 深夜以外の時間 ＋ 深夜の時給 × 深夜の時間。深夜（22時〜5時）の割増は、法律では25%以上です。深夜の時給を空欄にすると、時給の1.25倍で数えます。
2. **年収**: 月の給与 × 12。
3. **給与所得**: 年収 − 給与所得控除。2026・2027年分の給与所得控除は次のとおりです。
   | 年収 | 給与所得控除 |
   |---|---|
   | 220万円まで | 74万円（本則69万円 ＋ 2026・2027年分の特例5万円） |
   | 220万円超 360万円まで | 年収 × 30% ＋ 8万円 |
   | 360万円超 660万円まで | 年収 × 20% ＋ 44万円 |
   | 660万円超 850万円まで | 年収 × 10% ＋ 110万円 |
   | 850万円超 | 195万円 |

   660万円未満は、法律の表（所得税法 別表第五）にならい、年収を4,000円単位に切り捨ててから計算します。
4. **課税所得**: 給与所得 − 基礎控除 − 社会保険料控除（1,000円未満切り捨て）。
   - 基礎控除は、2026・2027年分なら、給与所得が489万円以下で104万円（本則62万円 ＋ 特例42万円）、489万円超655万円以下で67万円、それより上は62万円です（2,350万円超で減っていきます）。
   - 社会保険料控除は、1年に払った社会保険料の全額です（入力した場合だけ）。
5. **所得税**: 課税所得に税率をかけます（195万円以下 5%、330万円以下 10%、695万円以下 20%、…）。
6. **復興特別所得税**: 所得税の2.1%。所得税と合わせ、100円未満を切り捨てたものが年税額です。

例: 2026・2027年分では、給与だけなら年収178万円（74万円 ＋ 104万円）まで所得税はかかりません。年収300万円で、ほかに控除が無ければ年5万円ほどです。

2028年分以後は、2026年度の税制改正の大綱で示された予定（給与所得控除の最低69万円、基礎控除は給与所得132万円以下で99万円・それより上は62万円）で計算します。

## 3. 計算の正確さと限界

**正確なところ**

- 給与のほかに収入も控除も無く、入力した額面が1年間続くなら、年末調整で決まる所得税の年額とほぼ一致します。
- 給与所得控除は、220万円未満を国税庁が示す特例の表どおりに、それより上を法律の表と同じ4,000円刻みで計算しています。照合したのは、この文書に出てくる金額などの一部です。法律の表と細部が違えば、年税額で数十円程度ずれることがあります。

**ずれるところ**

- **毎月の天引き（源泉徴収）とは違います。** 毎月の天引きは、源泉徴収税額表（月額表）で決まります。
  - 2026年中の天引きは、2026年度の税制改正の前の表で計算されます。そのため天引きが多めになり、年末調整で戻ってきます。新しい表は 2027年1月の支払いから使われます。
  - 2か所以上で働いている場合や、勤務先に「扶養控除等申告書」を出していない場合は、天引きがずっと多くなります（乙欄）。差額は確定申告で精算します。
- **年の途中で働き方が変わる年は、別の計算になります。** 所得税は1年（1〜12月）の収入の合計にかかります。会社員として受け取った給与も、同じ年なら合算されます。この窓の計算は、同じ働き方が1年続いた場合の数字です。
- **ほかの所得控除を入れていません。** 扶養控除・配偶者控除・生命保険料控除・iDeCo・医療費控除・寄附金控除（ふるさと納税）などがあれば、税額はこれより少なくなります。
- **社会保険料を入れないと、所得税を多めに見積もります。** 社会保険料は全額が控除になるので、入れれば税額が下がります。
- **残業・休日出勤の割増、賞与、各種の手当は入れていません。** 1日8時間・週40時間を超えた分の割増（25%以上）や、深夜と重なった場合の割増（50%以上）は、深夜の時給や時給に含めて入力するしかありません。
- **2028年分以後は予定の数字です。** 2026年度の税制改正の大綱で、基礎控除などを物価に合わせて見直す方針も示されているので、金額は変わる見込みです。

## 4. 所得税のほかに必要なもの（未計算）

### 住民税

- 前の年（1〜12月）の所得に対して、翌年の6月から1年かけて払います。**収入が下がった最初の年は、前の年の多い収入に対する住民税を払う**ので、手取りが一時的に大きく減ります。
- 所得割（おおむね課税所得の10%）と、均等割（年5,000円程度。森林環境税を含む）。基礎控除は43万円で、所得税より小さいため、所得税がかからない年収でも住民税はかかることがあります。かからない収入の線は自治体によって違います。

### 健康保険・年金（勤務先で加入するか、自分で加入するか）

勤務先の健康保険・厚生年金に入るのは、おおむね次をすべて満たす場合です。

- 週の所定労働時間が20時間以上
- 2か月を超えて働く見込み
- 学生でない
- 勤務先の規模の条件を満たす（今は従業員51人以上。2027年10月から段階的に小さくなる予定）

月額8.8万円以上という賃金の条件は、2026年10月に無くなりました。

| | 勤務先で加入する場合（本人の負担） | 自分で加入する場合 |
|---|---|---|
| 健康保険 | 標準報酬月額 × 健康保険料率の半分（協会けんぽの全国平均は9.90%。都道府県で違う） | 国民健康保険。前の年の所得で決まり、市区町村ごとに計算の仕方が違う |
| 介護保険（40〜64歳） | 標準報酬月額 × 1.6%前後の半分 | 国民健康保険料に含まれる |
| 子ども・子育て支援金 | 標準報酬月額 × 0.23%の半分（2026年4月分から） | 国民健康保険料に含まれる（2026年度から） |
| 年金 | 厚生年金。標準報酬月額 × 18.3%の半分 | 国民年金。月17,920円（2026年度）、18,290円（2027年度） |

- 標準報酬月額は、実際の給与を区切りのよい等級に当てはめた額です。そのため、保険料は給与に比例して少しずつではなく、段階的に変わります。
- 2026年10月から、新しく加入する人の保険料の一部を勤務先が一時的に負担する仕組みも始まっています。

### 雇用保険

- 週20時間以上、31日以上働く見込みがあれば加入します（2028年10月からは週10時間以上）。
- 本人の負担は、給与（額面）の0.5%です（2026年度、一般の事業）。
