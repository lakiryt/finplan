# finplan

家計簿アプリから書き出したCSVを読み込み、家賃を除いた生活費の実績（平均・中央値・直近の平均）を集計し、家賃に回せる額の目安を出すツールです。

CSVはブラウザの中だけで処理され、どこにも送信されません。

## 使い方

```sh
npm install
npm run dev     # 開発サーバー
npm test        # テスト
npm run build   # 公開用ビルド（dist/）
npm run inspect -- <csv>   # 画面を開かずに集計を確認
```

`sample/sample.csv` は動作確認用の架空データです。本物のCSVは `csv/` に置きます（Gitの管理対象外）。

## 分類の考え方

カテゴリーはコードに書かず、設定で決めます。一般的な初期設定は `src/config/default-config.json` と `default-view.json` にあり、画面から編集・書き出し・読み込みができます。

自分用の初期設定は、同じ名前のファイルを `src/config/local/` に置くと開発サーバーで使われます（Gitの管理対象外で、公開用のビルドにも入りません）。

- **カテゴリーの割り当て**: カテゴリーごとに、生活費・住居費・収入・集計しない、のどれかの役割を持つグループに入れます。
- **ルール**: 「条件（元のカテゴリー・メモ・期間）」に一致した取引に「効果（カテゴリーの付け替え・グループの変更・複数月への按分）」を当てはめます。

実収入・実支出の考え方は [docs/real-income-expense.md](docs/real-income-expense.md) にまとめています。

構成や開発の方針は [CLAUDE.md](CLAUDE.md) を参照してください。
