# 家計簿CSV分析（finplan）

家計簿アプリから書き出したCSVを読み込み、目的に合わせて加工した収入・支出（生活費）の実績（平均・中央値・直近の平均）を見るツールです。手取りの見積もり（所得税・住民税・社会保険料）と合わせて、家賃や貯金など、これからの暮らしの計画の材料にできます。

CSVはブラウザの中だけで処理され、どこにも送信されません。

## 使い方

```sh
npm install
npm run dev     # 開発サーバー
npm test        # テスト
npm run build   # 公開用ビルド（dist/）
npm run inspect -- <csv>   # 画面を開かずに集計を確認
```

画面の「サンプルのデータで試す」は、架空の1年分のデータ（`src/domain/sample.ts`）を読み込みます。`sample/sample.csv` は動作確認用の架空データです。本物のCSVは `csv/` に置きます（Gitの管理対象外）。

## 加工の考え方

カテゴリーはコードに書かず、条件で指定します。「3. 加工」に、条件（収入側か支出側か・カテゴリー・メモ・期間・一覧から選んだ記録）を足していきます。反対側の差し引く先を選べば相殺、選ばなければ除外です。

- **相殺**: 条件に当たる記録を除き、反対側からも同じ額を差し引きます（割り勘の回収を支出から、家賃を収入から、など）。収支は変わりません。
- **除外**: 相手方が家計簿の外にあるもの（積立や貯金の引き出しなど、置き場所を移しただけのお金）を除きます。

一般的な初期設定は `src/config/default-processing.json` と `default-view.json` にあります。自分用の初期設定は、同じ名前のファイルを `src/config/local/` に置くと開発サーバーで使われます（Gitの管理対象外で、公開用のビルドにも入りません）。

考え方の要点は [docs/principles.md](docs/principles.md) にまとめています（詳しくは [実収入・実支出](docs/real-income-expense.md)、[相殺と生活費の定義](docs/offset-and-living-cost.md)、[手取りの見積もり](docs/take-home-pay.md)）。

構成や開発の方針は [CLAUDE.md](CLAUDE.md) を参照してください。
